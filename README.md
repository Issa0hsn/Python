# 🍕 Pizza Price Predictor (ML from Scratch)

## وصف المشروع
هذا المشروع هو تطبيق عملي لخوارزمية الانحدار الخطي (Linear Regression) التي درستها في كورس Stanford CS229. قمت ببناء الموديل من الصفر باستخدام NumPy  و matplotlib دون الاعتماد على مكتبات جاهزة، لفهم الرياضيات التي تقود تعلم الآلة.

## التقنيات المستخدمة
* Python
* NumPy (للعمليات المصفوفية والـ Vectorization)
* Matplotlib (لتصوير البيانات والنتائج)

##  المفاهيم الرياضية المطبقة
لقد قمت ببرمجة المعادلات التالية يدوياً:
* دالة التكلفة (Cost Function) 
* خوارزمية Gradient Descent: لتحديث الأوزان والوصول لأقل خطأ ممكن.

## 📊 النتائج
* دقة الموديل: وصلت الدقة إلى حوالي 94.1% (بنسبة خطأ 5.9%).
* تمكن الموديل من إيجاد أفضل خط يمثل العلاقة بين قطر البيتزا وسعرها.
